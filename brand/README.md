# housingmetrics.nyc brand assets

The mark is two overlapping bars on a warm cream tile. It reads two ways at
once: buildings on a skyline, and bars of a chart — housing production,
measured. The darkened intersection nods to layered data sources being
combined into one picture.

## Files

| File | Use |
| --- | --- |
| `logo.svg` | Primary horizontal lockup for light backgrounds |
| `logo-dark.svg` | Horizontal lockup for dark backgrounds |
| `logo-mark.svg` | Square mark alone (app tile, avatars, social) |
| `wordmark.svg` | Text-only wordmark for tight horizontal spaces |
| `favicon.svg` | Favicon / browser tab icon |

## Usage notes

- Keep clear space around the lockup of at least the tile's width on all sides ÷ 4.
- Don't recolor the bars or separate them from each other; the overlap is the
  signature of the mark.
- Use `logo-dark.svg` whenever the background is darker than mid-gray; the
  cream tile is shared between both variants.
- The mark stays legible down to 16 px; below 32 px prefer the mark alone
  over the full lockup.

## Type

The wordmark is set in [Inter](https://rsms.me/inter/) SemiBold (SIL Open Font
License), all lowercase, with the glyphs converted to outlines so the SVGs
render identically everywhere — no font installation needed. For text near the
logo, Inter or any neutral sans (Helvetica, Arial, system UI) pairs well.
